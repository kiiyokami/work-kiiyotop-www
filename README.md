# kiiyo.top

Personal site and project dump. Vanilla HTML, CSS, and JS — no frameworks, no build step.

## Stack

- HTML / CSS / JS
- [Geist](https://vercel.com/font) and Geist Mono via Google Fonts
- Served with nginx

## Structure

```
index.html   — markup
style.css    — all styles
favicon.svg  — site icon
```

## Running locally

Just open `index.html` in a browser, or serve the directory with any static file server:

```sh
npx serve .
# or
python3 -m http.server
```
